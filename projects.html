Adaptive Traffic Signal Management System

  1. Identified the problem of traffic congestion.
  2. Planned the system's traffic signal logic.
  3. Used C++ to implement the signal control logic.
  4. Used SQLite to store and manage data.
  5. Tested the system's behavior under different traffic conditions.

Technologies Used

  • C++
  • SQLite
  • Git and GitHub

Fikr Sign

Fikr Sign is a mobile application project designed to support communication between deaf and hearing people through Ethiopian Sign Language.

How I Built It

  1. Identified communication barriers between deaf and hearing people.
  2. Planned the app's user flow and key features.
  3. Designed the mobile app interface using UI/UX principles.
  4. Planned sign-to-text and text-to-sign translation features.

Technologies and Tools

  • Figma — UI/UX design
  • Flutter — mobile app development
  • Git and GitHub — version control
